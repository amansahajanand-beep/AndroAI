# Design System

Owner: Person 1.

- Stack: Tailwind CSS 4 + shadcn/ui (`apps/web/components.json`, components in `src/components/ui`).
- Tokens: CSS variables in `src/app/globals.css` (light/dark).
- Add components with `npx shadcn@latest add <component>` from `apps/web`.
- App-specific components go in `src/components`, not `ui/`.

Currently only `Button` is installed. Visual direction, typography and component guidelines are to be defined by Person 1.
